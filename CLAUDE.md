# Working in this repository

Read `HANDOFF.md` first: it holds the project state, Tamir's standing rules (branch, trailers,
style, deliverables) and the checks to run.

## Chat with Tamir (fixed preferences)

- Chat in Hebrew; code, comments and the site in English.
- **RTL-safe Hebrew.** Every paragraph, heading and list item starts with a Hebrew word (or with
  the RLM mark U+200F before a Latin character), never with an English word, a number followed by
  a period, or code. English terms and identifiers go in the middle or at the end of a sentence.
  Numbered lists are written as "‏1. **מילה** ..." with the RLM before the number. Otherwise the
  browser renders the line left-to-right and it reads backwards.
- Ask guiding questions (AskUserQuestion) before big changes; after each round deliver
  `QcommMentoring.zip` and `docs/downloads/yapp_project_map.html`.
