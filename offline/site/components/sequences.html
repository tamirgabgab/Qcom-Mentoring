    Sequencer and sequences¶

    Open on the project map →

    The sequencer is the traffic controller of an agent: sequences run on it, it arbitrates between them and hands one item at a time to the driver. The sequences are where the stimulus is actually described.

    subgraph seqs["sequences (objects)"]

        S2["yapp_exhaustive_seq<br/>runs the others"]
    end

    The sequencer¶

    Nothing to write beyond the boilerplate — the base class does all the work:

endclass : yapp_tx_sequencer

//------------------------------------------------------------------------------

  super.new(name, parent);
endfunction : new

    Anatomy of a sequence¶

    class yapp_1_seq extends yapp_base_seq;        // 1. base class with objections
  `uvm_object_utils(yapp_1_seq)                // 2. factory registration (object, not component!)
  extern function new(string name = "yapp_1_seq");   // 3. object constructor: name only
  extern task body();                                // 4. the stimulus
endclass : yapp_1_seq

function yapp_1_seq::new(string name = "yapp_1_seq");
  super.new(name);
endfunction : new

task yapp_1_seq::body();
  `uvm_info(get_type_name(), "Executing yapp_1_seq sequence", UVM_LOW)
  req = yapp_packet::type_id::create("req");           // create through the factory
  start_item(req);                                     // wait for the sequencer's grant
  if (!req.randomize() with { req.m_addr == 2'd1; })     // randomize, with constraints
    `uvm_error(get_type_name(), "req.randomize() failed")
  finish_item(req);                                    // to the driver; returns after item_done
endtask : body

    req is declared by uvm_sequence #(yapp_packet). Every item goes through the same four steps; the course material hides them behind a macro, this repository writes them out so you see what the macro does:

    Step Here Course macro
    create through the factory req = yapp_packet::type_id::create("req") `uvm_create(req)
    wait for the sequencer's grant start_item(req)
    randomize (with constraints), check the result if (!req.randomize() with { ... }) `uvm_error(...)
    send to the driver, wait for item_done finish_item(req) `uvm_send(req)
    all four the four lines above `uvm_do(req) / `uvm_do_with(req, {...})

    Between start_item and finish_item the sequence holds the sequencer, so keep that window short: no delays, no waiting for the DUT. yapp_incr_payload_seq moves the randomization before start_item, because it needs to edit the payload and recompute the parity before the driver sees the packet.

    A nested sequence is created the same way and started on the current sequencer, with the parent as the second argument so the sequencer sees the relationship (`uvm_do(seq_1) in the course):

    m_seq_1 = yapp_1_seq::type_id::create("seq_1");
if (!m_seq_1.randomize())
  `uvm_error(get_type_name(), "seq_1.randomize() failed")
m_seq_1.start(m_sequencer, this);       // blocks until seq_1.body() returns

//------------------------------------------------------------------------------
// yapp_base_seq: raises an objection while the sequence runs, so run_phase
// does not end before the last packet was delivered.
//------------------------------------------------------------------------------
class yapp_base_seq extends uvm_sequence #(yapp_packet);

  `uvm_object_utils(yapp_base_seq)

  extern function new(string name = "yapp_base_seq");
  extern task pre_body();

  extern task post_body();

endclass : yapp_base_seq

//------------------------------------------------------------------------------
// yapp_base_seq -- method implementations
//------------------------------------------------------------------------------

function yapp_base_seq::new(string name = "yapp_base_seq");
  super.new(name);
endfunction : new

//------------------------------------------------------------------------------
task yapp_base_seq::pre_body();
  uvm_phase phase = `YAPP_STARTING_PHASE;
  if (phase != null) begin
    phase.raise_objection(this, get_type_name());
  end
endtask : pre_body

//------------------------------------------------------------------------------
task yapp_base_seq::post_body();
  uvm_phase phase = `YAPP_STARTING_PHASE;
  if (phase != null) begin
    phase.drop_objection(this, get_type_name());
  end
endtask : post_body

  extern task body();

// yapp_repeat_addr_seq -- constraints
//------------------------------------------------------------------------------

constraint yapp_repeat_addr_seq::c_seq_addr {
  m_seq_addr != 2'd3;
}

//------------------------------------------------------------------------------
// yapp_repeat_addr_seq -- method implementations
//------------------------------------------------------------------------------

function yapp_repeat_addr_seq::new(string name = "yapp_repeat_addr_seq");
  super.new(name);

//------------------------------------------------------------------------------
task yapp_repeat_addr_seq::body();
  `uvm_info(get_type_name(),
            $sformatf("Executing yapp_repeat_addr_seq sequence (addr %0d)", m_seq_addr), UVM_LOW)
  req = yapp_packet::type_id::create("req");
  start_item(req);
  if (!req.randomize() with { req.m_addr == m_seq_addr; }) begin
    `uvm_error(get_type_name(), "req.randomize() failed")
  end
  finish_item(req);

  req = yapp_packet::type_id::create("req");
  start_item(req);
  if (!req.randomize() with { req.m_addr == m_seq_addr; }) begin
    `uvm_error(get_type_name(), "req.randomize() failed")
  end
  finish_item(req);
endtask : body

  extern function new(string name = "yapp_incr_payload_seq");

//------------------------------------------------------------------------------
// yapp_incr_payload_seq -- method implementations
//------------------------------------------------------------------------------

function yapp_incr_payload_seq::new(string name = "yapp_incr_payload_seq");
  super.new(name);
endfunction : new

//------------------------------------------------------------------------------
task yapp_incr_payload_seq::body();
  `uvm_info(get_type_name(), "Executing yapp_incr_payload_seq sequence", UVM_LOW)
  req = yapp_packet::type_id::create("req");   // build through the factory
  if (!req.randomize()) begin
    `uvm_error(get_type_name(), "Randomization failed")
  end
  foreach (req.m_payload[i]) begin
    req.m_payload[i] = i;
  end
  req.set_parity();                        // payload changed -> recompute parity
  start_item(req);   // hand it to the driver
  finish_item(req);
endtask : body

// yapp_coverage_seq.sv -- YAPP sequence library (Lab 3 base, Lab 5 library, Lab 7 opt.)
// Split out of yapp_tx_seqs.sv: one class per file.

//------------------------------------------------------------------------------
// yapp_coverage_seq (Lab 10): close the coverage model in one run.
// Every length bucket (MIN/SMALL/MEDIUM/LARGE/MAX) to every address 0..3,
// once with good and once with bad parity -> 5 x 4 x 2 = 40 packets.
//------------------------------------------------------------------------------
class yapp_coverage_seq extends yapp_base_seq;

  `uvm_object_utils(yapp_coverage_seq)

  extern function new(string name = "yapp_coverage_seq");
  extern task body();

endclass : yapp_coverage_seq

//------------------------------------------------------------------------------
// yapp_coverage_seq -- method implementations
//------------------------------------------------------------------------------

function yapp_coverage_seq::new(string name = "yapp_coverage_seq");
  super.new(name);
endfunction : new

//------------------------------------------------------------------------------
task yapp_coverage_seq::body();
  int lengths[5] = '{1, 5, 20, 50, 63};   // one value inside each bin
  `uvm_info(get_type_name(), "Executing yapp_coverage_seq sequence", UVM_LOW)
  for (int a = 0; a < 4; a++) begin
    foreach (lengths[i]) begin
      for (int bad = 0; bad < 2; bad++) begin
        req = yapp_packet::type_id::create("req");
        req.c_addr_legal.constraint_mode(0);
        req.c_parity_dist.constraint_mode(0);   // the sequence chooses the parity
        start_item(req);
        if (!req.randomize() with { req.m_addr == a;
                                    req.m_length == lengths[i];
                                    req.m_parity_type == (bad ? PARITY_TYPE_BAD : PARITY_TYPE_GOOD); }) begin
          `uvm_error(get_type_name(), "req.randomize() failed")
        end
        finish_item(req);
      end
    end
  end
endtask : body

task yapp_88_packets_seq::body();
  `uvm_info(get_type_name(), "Executing yapp_88_packets_seq sequence", UVM_LOW)
  for (int a = 0; a < 4; a++) begin
    for (int l = 1; l <= 22; l++) begin
      req = yapp_packet::type_id::create("req");
      req.c_addr_legal.constraint_mode(0);
      req.c_parity_dist.constraint_mode(0);   // the inline dist below replaces it
      start_item(req);
      if (!req.randomize() with { req.m_addr == a;
                                  req.m_length == l;
                                  req.m_parity_type dist { PARITY_TYPE_GOOD := 4, PARITY_TYPE_BAD := 1 }; }) begin
        `uvm_error(get_type_name(), "req.randomize() failed")
      end
      finish_item(req);
    end
  end
endtask : body

//------------------------------------------------------------------------------
// yapp_pkt_seq: one packet whose address, length and parity the test chooses by
// randomizing the sequence with an inline constraint, for example
//   seq.randomize() with { pkt_addr == 3; pkt_len == 20; }
// The soft constraints give a legal, good packet when the test says nothing.
// The packet that went out stays in `req`, so the test can compare the DUT's
// memories and counters against exactly what was sent.
//------------------------------------------------------------------------------
class yapp_pkt_seq extends yapp_base_seq;

  rand bit[1:0]     m_pkt_addr;
  rand bit[5:0]     m_pkt_len;
  rand parity_type_e m_pkt_parity;

  `uvm_object_utils(yapp_pkt_seq)

  extern constraint c_len;
  extern constraint c_legal;
  extern constraint c_parity;

  extern function new(string name = "yapp_pkt_seq");
  extern task body();

endclass : yapp_pkt_seq

//------------------------------------------------------------------------------
// yapp_pkt_seq -- constraints
//------------------------------------------------------------------------------

constraint yapp_pkt_seq::c_len {
  m_pkt_len inside {[1:63]};
}

//------------------------------------------------------------------------------
constraint yapp_pkt_seq::c_legal {
  soft m_pkt_addr != 2'd3;
}

//------------------------------------------------------------------------------
constraint yapp_pkt_seq::c_parity {
  m_pkt_parity != PARITY_TYPE_UNDEFINED;
  soft m_pkt_parity == PARITY_TYPE_GOOD;
}

//------------------------------------------------------------------------------
// yapp_pkt_seq -- method implementations
//------------------------------------------------------------------------------

function yapp_pkt_seq::new(string name = "yapp_pkt_seq");
  super.new(name);
endfunction : new

//------------------------------------------------------------------------------
task yapp_pkt_seq::body();
  `uvm_info(get_type_name(), $sformatf("Executing yapp_pkt_seq (addr %0d, length %0d, %s)",
                                       m_pkt_addr, m_pkt_len, m_pkt_parity.name()), UVM_LOW)
  req = yapp_packet::type_id::create("req");
  req.c_addr_legal.constraint_mode(0);      // the test may ask for address 3
  req.c_parity_dist.constraint_mode(0);     // the sequence chooses the parity
  start_item(req);
  if (!req.randomize() with { req.m_addr        == m_pkt_addr;
                              req.m_length      == m_pkt_len;

    `uvm_error(get_type_name(), "req.randomize() failed")

endtask : body

//------------------------------------------------------------------------------
// yapp_boundary_seq.sv -- YAPP sequence library (test-plan sequences)
// Split out of yapp_tx_seqs.sv: one class per file.
//------------------------------------------------------------------------------

//------------------------------------------------------------------------------
// yapp_boundary_seq: packets around the maxpktsize limit, to every address
// including the illegal 3. For each address the lengths maxpktsize - 1,
// maxpktsize, maxpktsize + 1 and 63 are sent (those that exist in 1..63), all
// with good parity. The sequence counts what it sent, so the test can predict
// the counters and the scoreboard without re-deriving the drop rules.
//------------------------------------------------------------------------------
class yapp_boundary_seq extends yapp_base_seq;

  rand bit[5:0] m_maxpktsize;                // the value programmed into ctrl_reg

  // Bookkeeping for the test
  int m_sent_total;
  int m_sent_oversized;                       // length > maxpktsize
  int m_sent_per_addr[4];                     // per address, dropped or not
  int m_sent_forwarded;                       // legal address and not oversized

  `uvm_object_utils(yapp_boundary_seq)

  extern constraint c_max;

  extern function new(string name = "yapp_boundary_seq");
  extern task body();

endclass : yapp_boundary_seq

//------------------------------------------------------------------------------
// yapp_boundary_seq -- constraints
//------------------------------------------------------------------------------

constraint yapp_boundary_seq::c_max {
  m_maxpktsize inside {[2:62]};
}

//------------------------------------------------------------------------------
// yapp_boundary_seq -- method implementations
//------------------------------------------------------------------------------

function yapp_boundary_seq::new(string name = "yapp_boundary_seq");
  super.new(name);
endfunction : new

//------------------------------------------------------------------------------
task yapp_boundary_seq::body();
  int lens[$];
  int cand[4];
  cand = '{m_maxpktsize - 1, m_maxpktsize, m_maxpktsize + 1, 63};
  foreach (cand[i]) begin
    if (cand[i] >= 1 && cand[i] <= 63 && !(cand[i] inside {lens})) begin
      lens.push_back(cand[i]);
    end
  end
  `uvm_info(get_type_name(), $sformatf("Executing yapp_boundary_seq (maxpktsize %0d, lengths %p)",
                                       m_maxpktsize, lens), UVM_LOW)
  m_sent_total = 0;
  m_sent_oversized = 0;
  m_sent_forwarded = 0;
  foreach (m_sent_per_addr[i]) begin
    m_sent_per_addr[i] = 0;
  end
  for (int a = 0; a < 4; a++) begin
    foreach (lens[i]) begin
      req = yapp_packet::type_id::create("req");
      req.c_addr_legal.constraint_mode(0);
      req.c_parity_dist.constraint_mode(0);   // the sequence chooses the parity
      start_item(req);
      if (!req.randomize() with { req.m_addr        == a;
                                  req.m_length      == lens[i];
                                  req.m_parity_type == PARITY_TYPE_GOOD; }) begin
        `uvm_error(get_type_name(), "req.randomize() failed")
      end
      finish_item(req);
      m_sent_total++;
      m_sent_per_addr[a]++;
      if (lens[i] > m_maxpktsize) begin
        m_sent_oversized++;
      end
      if (a != 3 && lens[i] <= m_maxpktsize) begin
        m_sent_forwarded++;
      end
    end
  end
endtask : body

//------------------------------------------------------------------------------
// yapp_gap_seq.sv -- YAPP sequence library (test-plan sequences)
//------------------------------------------------------------------------------

//------------------------------------------------------------------------------
// yapp_gap_seq: `count` short good packets to the legal addresses with chosen
// gaps (packet_delay = idle cycles before the packet). The first packet waits
// 3 cycles; after it the gaps cycle 1, 2, 3, 0, 1, 2, 3, 0, ... so every gap
// from back to back (0) to "longer" (3) appears. The sequence counts the gaps
// it asked for between its packets, in the same four classes as the monitor
// (0, 1, 2, 3 or more), so the test can compare planned and measured gaps. The
// first packet is not counted: its gap depends on what the bus did before.
//------------------------------------------------------------------------------
class yapp_gap_seq extends yapp_base_seq;

  rand int unsigned m_count;

  // Bookkeeping for the test: gaps asked for after the first packet, per class 0, 1, 2, 3+
  int m_planned_gap[4];

  `uvm_object_utils(yapp_gap_seq)

  extern constraint c_count;

  extern function new(string name = "yapp_gap_seq");
  extern task body();

endclass : yapp_gap_seq

//------------------------------------------------------------------------------
// yapp_gap_seq -- constraints
//------------------------------------------------------------------------------

constraint yapp_gap_seq::c_count {
  m_count inside {[8:40]};
}

//------------------------------------------------------------------------------
// yapp_gap_seq -- method implementations
//------------------------------------------------------------------------------

function yapp_gap_seq::new(string name = "yapp_gap_seq");
  super.new(name);
endfunction : new

//------------------------------------------------------------------------------
task yapp_gap_seq::body();
  int gap;
  `uvm_info(get_type_name(), $sformatf("Executing yapp_gap_seq (%0d packets)", m_count), UVM_LOW)
  foreach (m_planned_gap[i]) begin
    m_planned_gap[i] = 0;
  end
  for (int i = 0; i < m_count; i++) begin
    gap = (i == 0) ? 3 : i % 4;
    req = yapp_packet::type_id::create("req");
    req.c_parity_dist.constraint_mode(0);   // the sequence chooses the parity
    req.c_delay.constraint_mode(0);         // the sequence chooses the gap (0 included)
    start_item(req);
    if (!req.randomize() with { req.m_length       inside {[1:8]};
                                req.m_parity_type  == PARITY_TYPE_GOOD;
                                req.m_packet_delay == gap; }) begin
      `uvm_error(get_type_name(), "req.randomize() failed")
    end
    finish_item(req);
    if (i > 0) begin
      m_planned_gap[gap]++;
    end
  end
endtask : body

//------------------------------------------------------------------------------
// yapp_random_burst_seq.sv -- YAPP sequence library (random tests)
//------------------------------------------------------------------------------

//------------------------------------------------------------------------------
// yapp_random_burst_seq: `count` packets whose address, length, parity and gap
// are drawn per packet from weights the caller sets (the knobs below), so one
// burst can mix legal and illegal addresses, lengths around the maxpktsize in
// force, bad parity and back-to-back packets.
//
// Length of each packet, in this order of the percent knobs:
//   short_pct     1..3 bytes (the shortest packets: bad-parity storms)
//   long_pct      40..63 bytes (longer than a channel FIFO: back-pressure)
//   boundary_pct  one of 1, maxpktsize-1, maxpktsize, maxpktsize+1, 63
//                 (clipped to 1..63)
//   otherwise     1..63
// Gap before each packet (idle cycles): gap0_pct back to back, gap_short_pct
// 1..3, otherwise 4..20.
//
// Every choice comes from rnd:: and is pinned with `==` in randomize() with
// the packet's own address / parity / delay constraints switched off (dist and
// == on the same field do not mix in Verilator); the payload stays random.
//------------------------------------------------------------------------------
class yapp_random_burst_seq extends yapp_base_seq;

  rand int unsigned m_count;

  // Knobs (percent unless said otherwise)
  bit[5:0] m_maxpktsize   = 6'd63;           // the value in force, for the boundary lengths
  int       m_addr3_pct    = 5;               // packets to the illegal address 3
  int       m_bad_pct      = 15;              // packets with bad parity
  int       m_short_pct    = 0;
  int       m_long_pct     = 0;
  int       m_boundary_pct = 40;
  int       m_gap0_pct     = 25;
  int       m_gap_short_pct = 35;

  // What was sent, for the [TEST] stage lines
  int m_sent_per_addr[4];
  int m_sent_bad;
  int m_sent_gap0;
  int m_sent_len_min;
  int m_sent_len_max;

  `uvm_object_utils(yapp_random_burst_seq)

  extern constraint c_count;

  extern function new(string name = "yapp_random_burst_seq");
  extern task body();

  // One draw of each field, from the knobs
  extern function bit[1:0] pick_addr();
  extern function bit[5:0] pick_length();
  extern function int       pick_gap();

  // "addr0..3 a/b/c/d, bad n, gap0 n, len lo..hi"
  extern function string summary();

endclass : yapp_random_burst_seq

//------------------------------------------------------------------------------
// yapp_random_burst_seq -- constraints
//------------------------------------------------------------------------------

constraint yapp_random_burst_seq::c_count {
  m_count inside {[1:100]};
}

//------------------------------------------------------------------------------
// yapp_random_burst_seq -- method implementations
//------------------------------------------------------------------------------

function yapp_random_burst_seq::new(string name = "yapp_random_burst_seq");
  super.new(name);
endfunction : new

//------------------------------------------------------------------------------
task yapp_random_burst_seq::body();
  bit[1:0]     a;
  bit[5:0]     len;
  parity_type_e par;
  int           gap;
  `uvm_info(get_type_name(), $sformatf("Executing yapp_random_burst_seq (%0d packets, maxpktsize %0d)",
                                       m_count, m_maxpktsize), UVM_LOW)
  foreach (m_sent_per_addr[i]) begin
    m_sent_per_addr[i] = 0;
  end
  m_sent_bad     = 0;
  m_sent_gap0    = 0;
  m_sent_len_min = 64;
  m_sent_len_max = 0;
  for (int i = 0; i < m_count; i++) begin
    a   = pick_addr();
    len = pick_length();
    par = (rnd::get_int(0, 99, "yapp_random_burst_seq.parity") < m_bad_pct) ? PARITY_TYPE_BAD : PARITY_TYPE_GOOD;
    gap = pick_gap();
    req = yapp_packet::type_id::create("req");
    req.c_addr_legal.constraint_mode(0);    // the sequence chooses the address (3 included)
    req.c_parity_dist.constraint_mode(0);   // ... the parity
    req.c_delay.constraint_mode(0);         // ... and the gap (0 included)
    start_item(req);
    if (!req.randomize() with { req.m_addr         == a;
                                req.m_length       == len;
                                req.m_parity_type  == par;
                                req.m_packet_delay == gap; }) begin
      `uvm_error(get_type_name(), "req.randomize() failed")
    end
    finish_item(req);
    m_sent_per_addr[a]++;
    if (par == PARITY_TYPE_BAD) begin
      m_sent_bad++;
    end
    if (gap == 0) begin
      m_sent_gap0++;
    end
    if (len < m_sent_len_min) begin
      m_sent_len_min = len;
    end
    if (len > m_sent_len_max) begin
      m_sent_len_max = len;
    end
  end
endtask : body

//------------------------------------------------------------------------------
function bit[1:0] yapp_random_burst_seq::pick_addr();
  if (rnd::get_int(0, 99, "yapp_random_burst_seq.addr3") < m_addr3_pct) begin
    return 2'd3;
  end
  return 2'(rnd::get_int(0, 2, "yapp_random_burst_seq.addr"));
endfunction : pick_addr

//------------------------------------------------------------------------------
function bit[5:0] yapp_random_burst_seq::pick_length();
  int r;
  int len;
  r = rnd::get_int(0, 99, "yapp_random_burst_seq.length_class");
  if (r < m_short_pct) begin
    len = rnd::get_int(1, 3, "yapp_random_burst_seq.short_length");
  end else if (r < m_short_pct + m_long_pct) begin
    len = rnd::get_int(40, 63, "yapp_random_burst_seq.long_length");
  end else if (r < m_short_pct + m_long_pct + m_boundary_pct) begin
    case (rnd::get_int(0, 4, "yapp_random_burst_seq.boundary"))
      0:       len = 1;
      1:       len = int'(m_maxpktsize) - 1;
      2:       len = int'(m_maxpktsize);
      3:       len = int'(m_maxpktsize) + 1;
      default: len = 63;
    endcase
  end else begin
    len = rnd::get_int(1, 63, "yapp_random_burst_seq.length");
  end
  if (len < 1) begin
    len = 1;
  end
  if (len > 63) begin
    len = 63;
  end
  return 6'(len);
endfunction : pick_length

//------------------------------------------------------------------------------
function int yapp_random_burst_seq::pick_gap();
  int r;
  r = rnd::get_int(0, 99, "yapp_random_burst_seq.gap_class");
  if (r < m_gap0_pct) begin
    return 0;
  end
  if (r < m_gap0_pct + m_gap_short_pct) begin
    return rnd::get_int(1, 3, "yapp_random_burst_seq.short_gap");
  end
  return rnd::get_int(4, 20, "yapp_random_burst_seq.gap");
endfunction : pick_gap

//------------------------------------------------------------------------------
function string yapp_random_burst_seq::summary();
  return $sformatf("addr0..3 %0d/%0d/%0d/%0d, bad parity %0d, gap 0 %0d, length %0d..%0d",
                   m_sent_per_addr[0], m_sent_per_addr[1], m_sent_per_addr[2], m_sent_per_addr[3],
                   m_sent_bad, m_sent_gap0, m_sent_len_min, m_sent_len_max);
endfunction : summary

    Randomization failures (Lab 5)¶

    An inline constraint that contradicts a constraint of the item makes randomize() fail: it returns 0, the sequence reports req.randomize() failed, the item keeps its old values and finish_item still sends it. In batch mode the simulation does not stop. That is what happened in Lab 5 when short_yapp_packet forbade address 2 while yapp_012_seq asked for it. Debug with -gui -access rwc (SimVision stops on the failure and opens the constraint manager) or simply read the warning: it names the conflicting constraints.

    Common mistakes¶

    • `uvm_component_utils on a sequence (it is an object).
    • A constructor with a parent argument.
    • Forgetting super.new(name).
    • Ignoring the return value of randomize(): the item is sent with stale values and nobody notices.
    • Calling finish_item without start_item (or start_item on a different handle than finish_item).
    • Raising an objection in a sub-sequence without the null check (starting_phase is null there).
    • A forever sequence (channel_rx_resp_seq) with an objection: the test never ends.
