    Lab 1 — Creating a stimulus model¶

    Open on the project map →

    Directory: labs/lab01_data · Files: sv/yapp_packet.sv, sv/yapp_pkg.sv, tb/top.sv, tb/run.f

    Objective¶

    Model the YAPP packet as a UVM data item and explore what the base class gives you once the item describes its fields: printing, copying, cloning, comparing.

    Concepts¶

    uvm_sequence_item · `uvm_object_utils · do_print / do_copy / do_compare / do_pack / do_unpack / do_record · rand and constraints · dist · post_randomize() · control knobs · packages

    No uvm_field_* macros here

    The course material lists the fields between `uvm_object_utils_begin and `uvm_object_utils_end with `uvm_field_int(addr, UVM_ALL_ON) and so on, and the macros generate print, copy, compare, pack and record for you. This repository writes those methods out (do_print uses printer.print_field, do_compare uses comparer.compare_field_int, …) so you see what each pkt.print() or pkt.compare() actually does — and what it costs to add a field.

    Solution¶

    1. sv/yapp_packet.sv¶

    //------------------------------------------------------------------------------
// yapp_packet.sv -- the YAPP packet as a UVM sequence item (Lab 1)
//
//          7   6   5   4   3   2   1   0
//        +-----------------------+-------+
// byte 0 |      length[5:0]      | addr  |  header
//        +-----------------------+-------+
// byte 1 |          payload[0]           |  \
//        |             ...               |   > N == length, 1..63 bytes
// byte N |         payload[N-1]          |  /
//        +-------------------------------+
// byte N+1 |          parity             |  even bitwise parity (XOR) of header and payload
//        +-------------------------------+
//   figure: docs/assets/packet_structure.svg (see README.md in this directory)
//
// Control knobs (not part of the packet on the wire):
//   parity_type  -- PARITY_TYPE_GOOD / PARITY_TYPE_BAD, decides what set_parity() writes
//   packet_delay -- idle clock cycles the driver inserts before the packet
//------------------------------------------------------------------------------

class yapp_packet extends uvm_sequence_item;

  // Packet fields
  rand bit[1:0] m_addr;
  rand bit[5:0] m_length;
  rand bit[7:0] m_payload[];
       bit[7:0] m_parity;          // computed, never randomized directly

  // Control knobs
  rand parity_type_e m_parity_type;
  rand int           m_packet_delay;

  `uvm_object_utils(yapp_packet)

  // Constraints (named so sequences can switch them off)
  extern constraint c_addr_legal;
  extern constraint c_length;
  extern constraint c_parity_defined;
  extern constraint c_parity_dist;
  extern constraint c_delay;

  // Printing, copying, comparing, packing and recording are written by hand
  // (do_print / do_copy / do_compare / do_pack / do_unpack / do_record below):
  // no uvm_field_* automation.
  extern virtual function void do_copy(uvm_object rhs);
  extern virtual function bit  do_compare(uvm_object rhs, uvm_comparer comparer);
  extern virtual function void do_print(uvm_printer printer);
  extern virtual function void do_pack(uvm_packer packer);
  extern virtual function void do_unpack(uvm_packer packer);
  extern virtual function void do_record(uvm_recorder recorder);

  extern function new(string name = "yapp_packet");

  // Correct parity: XOR of header and every payload byte
  extern function bit[7:0] calc_parity();

  // Write the parity byte according to the m_parity_type knob.
  // A bad parity flips one random bit of the correct value.
  extern function void set_parity();

  // Called automatically after every successful randomize(): sizes the
  // payload to `m_length` if the solver did not, then sets the parity
  extern function void post_randomize();

endclass : yapp_packet

//------------------------------------------------------------------------------
// yapp_packet -- constraints
//------------------------------------------------------------------------------

constraint yapp_packet::c_addr_legal {
  m_addr != 2'd3;
}

//------------------------------------------------------------------------------
constraint yapp_packet::c_length {
  m_length inside {[1:63]};
  m_payload.size() == m_length;
}

//------------------------------------------------------------------------------
constraint yapp_packet::c_parity_defined {
  m_parity_type != PARITY_TYPE_UNDEFINED;
}

//------------------------------------------------------------------------------
constraint yapp_packet::c_parity_dist {
  m_parity_type dist { PARITY_TYPE_GOOD := 5, PARITY_TYPE_BAD := 1 };
}

//------------------------------------------------------------------------------
constraint yapp_packet::c_delay {
  m_packet_delay inside {[1:20]};
}

//------------------------------------------------------------------------------
// yapp_packet -- method implementations
//------------------------------------------------------------------------------

function yapp_packet::new(string name = "yapp_packet");
  super.new(name);
endfunction : new

//------------------------------------------------------------------------------
function bit[7:0] yapp_packet::calc_parity();
  calc_parity = {m_length, m_addr};
  foreach (m_payload[i]) begin
    calc_parity ^= m_payload[i];
  end
endfunction : calc_parity

//------------------------------------------------------------------------------
function void yapp_packet::set_parity();
  int unsigned bad_bit;
  m_parity = calc_parity();
  if (m_parity_type == PARITY_TYPE_BAD) begin
    // draw the bit once and flip it: two draws would pick two different bits
    // and leave the parity correct about half of the time
    bad_bit = rnd::get_index(8, {get_full_name(), ".bad_parity_bit"});
    m_parity[bad_bit] = ~m_parity[bad_bit];
  end
endfunction : set_parity

//------------------------------------------------------------------------------
function void yapp_packet::post_randomize();
  // Some solvers (Verilator 5.052) do not resize payload when randomize() is
  // called with an inline `with {...}`. Size it here: no sequence constrains
  // the payload bytes, so nothing is lost.
  if (m_payload.size() != m_length) begin
    m_payload = rnd::get_bytes(m_length, {get_full_name(), ".payload"});
  end
  set_parity();
endfunction : post_randomize

//------------------------------------------------------------------------------
function void yapp_packet::do_copy(uvm_object rhs);
  yapp_packet rhs_;
  if (!$cast(rhs_, rhs)) begin
    `uvm_fatal(get_type_name(), "do_copy: rhs is not a yapp_packet")
  end
  super.do_copy(rhs);
  m_addr         = rhs_.m_addr;
  m_length       = rhs_.m_length;
  m_payload      = rhs_.m_payload;
  m_parity       = rhs_.m_parity;
  m_parity_type  = rhs_.m_parity_type;
  m_packet_delay = rhs_.m_packet_delay;
endfunction : do_copy

//------------------------------------------------------------------------------
function bit yapp_packet::do_compare(uvm_object rhs, uvm_comparer comparer);
  yapp_packet rhs_;
  if (!$cast(rhs_, rhs)) begin
    return 0;
  end
  do_compare = super.do_compare(rhs, comparer);
  do_compare &= comparer.compare_field_int("addr", m_addr, rhs_.m_addr, $bits(m_addr), UVM_HEX);
  do_compare &= comparer.compare_field_int("length", m_length, rhs_.m_length, $bits(m_length), UVM_DEC);
  do_compare &= comparer.compare_field_int("payload.size()", m_payload.size(), rhs_.m_payload.size(), 32, UVM_DEC);
  foreach (m_payload[i]) begin
    if (i < rhs_.m_payload.size()) begin
      do_compare &= comparer.compare_field_int($sformatf("payload[%0d]", i), m_payload[i], rhs_.m_payload[i], $bits(m_payload[i]), UVM_HEX);
    end
  end
  do_compare &= comparer.compare_field_int("parity", m_parity, rhs_.m_parity, $bits(m_parity), UVM_HEX);
  do_compare &= comparer.compare_field_int("parity_type", m_parity_type, rhs_.m_parity_type, $bits(m_parity_type));
endfunction : do_compare

//------------------------------------------------------------------------------
function void yapp_packet::do_print(uvm_printer printer);
  super.do_print(printer);
  printer.print_field("addr", m_addr, $bits(m_addr), UVM_HEX);
  printer.print_field("length", m_length, $bits(m_length), UVM_DEC);
  printer.print_array_header("payload", m_payload.size());
  foreach (m_payload[i]) begin
    printer.print_field($sformatf("[%0d]", i), m_payload[i], $bits(m_payload[i]), UVM_HEX, "[");
  end
  printer.print_array_footer(m_payload.size());
  printer.print_field("parity", m_parity, $bits(m_parity), UVM_HEX);
  printer.print_generic("parity_type", "parity_type_e", $bits(m_parity_type), m_parity_type.name());
  printer.print_field("packet_delay", m_packet_delay, $bits(m_packet_delay), UVM_DEC);
endfunction : do_print

//------------------------------------------------------------------------------
function void yapp_packet::do_pack(uvm_packer packer);
  super.do_pack(packer);
  packer.pack_field_int(m_addr, $bits(m_addr));
  packer.pack_field_int(m_length, $bits(m_length));
  packer.pack_field_int(m_payload.size(), 32);
  foreach (m_payload[i]) begin
    packer.pack_field_int(m_payload[i], $bits(m_payload[i]));
  end
  packer.pack_field_int(m_parity, $bits(m_parity));
  packer.pack_field_int(m_parity_type, $bits(m_parity_type));
  packer.pack_field_int(m_packet_delay, $bits(m_packet_delay));
endfunction : do_pack

//------------------------------------------------------------------------------
function void yapp_packet::do_unpack(uvm_packer packer);
  super.do_unpack(packer);
  m_addr = packer.unpack_field_int($bits(m_addr));
  m_length = packer.unpack_field_int($bits(m_length));
  m_payload = new[packer.unpack_field_int(32)];
  foreach (m_payload[i]) begin
    m_payload[i] = packer.unpack_field_int($bits(m_payload[i]));
  end
  m_parity = packer.unpack_field_int($bits(m_parity));
  m_parity_type = parity_type_e'(packer.unpack_field_int($bits(m_parity_type)));
  m_packet_delay = packer.unpack_field_int($bits(m_packet_delay));
endfunction : do_unpack

//------------------------------------------------------------------------------
function void yapp_packet::do_record(uvm_recorder recorder);
  super.do_record(recorder);
  recorder.record_field("addr", m_addr, $bits(m_addr), UVM_HEX);
  recorder.record_field("length", m_length, $bits(m_length), UVM_DEC);
  foreach (m_payload[i]) begin
    recorder.record_field($sformatf("payload[%0d]", i), m_payload[i], $bits(m_payload[i]), UVM_HEX);
  end
  recorder.record_field("parity", m_parity, $bits(m_parity), UVM_HEX);
  recorder.record_string("parity_type", m_parity_type.name());
  recorder.record_field("packet_delay", m_packet_delay, $bits(m_packet_delay), UVM_DEC);
endfunction : do_record

    Points worth a second look:

    • parity_type_e is declared outside the class so that tests and sequences can write PARITY_TYPE_GOOD without a scope prefix.
    • m_parity is not rand. It is derived: post_randomize() calls set_parity(), which uses calc_parity() for a good packet and flips one bit for a bad one. The bit is drawn once, from the common random library (rnd::get_index(8, ...), see Random values), and then flipped. Writing m_parity[$urandom_range(7,0)] = ~m_parity[$urandom_range(7,0)] draws twice, picks two different bits and leaves the parity correct about half of the time (a real bug, found by the first simulation of this code).
    • Named constraints can be disabled later (c_addr_legal.constraint_mode(0)).
    • do_compare does not look at m_packet_delay (the course's UVM_NOCOMPARE): two identical packets sent with different gaps still compare equal.
    • The class body only declares the methods (extern); their bodies follow endclass as function yapp_packet::set_parity();. Read the class to learn what a packet can do, read below it to learn how.

    3. tb/top.sv¶

    //------------------------------------------------------------------------------
// top.sv -- Lab 1: randomize and print five YAPP packets
//------------------------------------------------------------------------------
`timescale 1ns/1ns

module top;

  import uvm_pkg::*;
  import rand_util_pkg::*;   // rnd:: random values (common/rand_util_pkg.sv)
  `include "uvm_macros.svh"
  import yapp_pkg::*;

  yapp_packet m_pkt;

  initial begin
    m_pkt = new("pkt");
    repeat (5) begin
      if (!m_pkt.randomize()) begin
        `uvm_error("TOP", "Packet randomization failed")
      end
      m_pkt.print();
    end

    //--------------------------------------------------------------------
    // Optional: explore copy / compare / print (do_copy, do_compare, do_print in yapp_packet)
    //--------------------------------------------------------------------
    begin
      yapp_packet copy_pkt, clone_pkt;

      // copy(): field-by-field copy into an EXISTING object
      copy_pkt = new("copy_pkt");
      copy_pkt.copy(m_pkt);

      // clone(): allocate a NEW object and copy into it (returns uvm_object)
      $cast(clone_pkt, m_pkt.clone());
      clone_pkt.set_name("clone_pkt");

      // compare(): returns 1 when every field flagged for compare matches
      `uvm_info("TOP", $sformatf("copy  compare -> %0d", m_pkt.compare(copy_pkt)),  UVM_NONE)
      `uvm_info("TOP", $sformatf("clone compare -> %0d", m_pkt.compare(clone_pkt)), UVM_NONE)
      clone_pkt.m_payload[0] = ~clone_pkt.m_payload[0];
      `uvm_info("TOP", $sformatf("modified clone compare -> %0d (miscompare is reported above)",
                                 m_pkt.compare(clone_pkt)), UVM_NONE)

      // The same packet with the table and the tree printer
      m_pkt.print(uvm_default_table_printer);
      m_pkt.print(uvm_default_tree_printer);
    end
  end

endmodule : top

Every m_addr is 0, 1 or 2; m_payload has exactly m_length entries; about one packet in six shows PARITY_TYPE_BAD with a parity byte that differs from the XOR of the other bytes. Then the optional section prints copy compare -> 1, clone compare -> 1, a miscompare message for the modified clone, and the same packet in table and tree layout.

    Try this¶

    Small changes to make in start/ once the lab works, each with a question; the answer unfolds.

    Make bad parity rarer: change the dist in c_parity_type so that only one packet in twenty has PARITY_TYPE_BAD. Run again -- how many of the five packets are bad now, and why can the answer still be two?

    m_parity_type dist { PARITY_TYPE_GOOD := 19, PARITY_TYPE_BAD := 1 }. The distribution is a probability, not a quota: with five packets you usually see none, but two bad ones are possible. Run with another seed (SEED=7) to see it change.

    Add a constraint that forbids m_length == 1. Which packets change, and what does print() show for m_payload now?

    constraint c_no_one { m_length != 1; } -- every packet still prints m_length entries of m_payload, there are simply no one-byte packets. post_randomize() keeps the parity right because it runs after the constraints.

    Checkpoint questions¶

    Why does m_parity not have the rand qualifier?

    Because its value is a function of the other fields. If it were random it would be wrong most of the time, and if you then constrained it to be correct you could no longer inject parity errors. A derived value is computed in post_randomize().

    What does m_payload.size() == m_length do during randomization?

    The solver sizes the dynamic array to match m_length; the elements are then randomized. Without it the array keeps whatever size it had (0 at first).

    What is the difference between copy() and clone()?

    copy() copies the fields into an existing object. clone() allocates a new object (through the factory), copies into it and returns it as a uvm_object, hence the $cast.

    Where does print() get the field names and formats from?

    From yapp_packet::do_print: one printer.print_field("length", length, $bits(length), UVM_DEC) per field (UVM_DEC prints length in decimal, the others use hex), print_array_header/footer around the payload and print_generic for the enum. print() itself belongs to uvm_object; it picks the printer (table or tree) and calls do_print.
