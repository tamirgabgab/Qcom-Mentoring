    Tests¶

    Every test class of the project and the labs, in course order (the test-plan tests last), with the purpose of its plan. The table is generated from the model by make map; the full plan of each test (stages, expected result, the items it verifies) is on the test plan page and in the Test plan view of the project map; its runs are in the regression results.

    Test Lab Extends Purpose
    base_test 2 uvm_test The skeleton every test extends: builds router_tb, keeps the run alive 200 ns after the last objection, reports unused settings.
    set_config_test 4 base_test Lab 4: a passive agent through the configuration database -- and why the sequence setting lives in a virtual function.
    short_packet_test 4 base_test Lab 4: the factory override in action -- the sequence asks for yapp_packet and gets short_yapp_packet.
    exhaustive_seq_test 5 base_test Lab 5: one sequence that runs every sequence of the library once (sequences starting sub-sequences).
    incr_payload_test 5 base_test Lab 5: a sequence that shapes the payload after randomisation.
    yapp_012_test 6 base_test Lab 6: the first packets into the real DUT -- one per channel, so the connection is easy to check in the waveform.
    simple_test 7 base_test Lab 7: every UVC talking to the DUT with the default sequences only.
    test_uvc_integration 7 base_test Lab 7: 88 packets of every length and address against a router programmed for small packets.
    router_simple_mcseq_test 8 base_test Lab 8: one multichannel sequence on the virtual sequencer programs the router and sends the packets in order.
    scoreboard_drop_test 9A router_simple_mcseq_test Lab 9A: the negative check -- full-size packets while maxpktsize is 20, so the router drops some and the scoreboard must notice.
    coverage_test 10 base_test Lab 10: stimulus written to close the functional coverage model of the YAPP packets (yapp_pkt_cg in yapp_pkt_coverage, fed by the monitor).
    uvm_mem_walk_test 11B base_test Lab 11B: the built-in memory sequence walks yapp_mem; the RO yapp_pkt_mem is skipped.
    uvm_reset_test 11B base_test Lab 11B: the built-in register sequence that reads every register after reset.
    reg_access_test 11C base_test Lab 11C: hand-written front-door and backdoor checks on one RW and one RO register.
    reg_function_check_test 11C reg_function_test Lab 11C (optional): the same test with the model checking every read itself.
    reg_function_test 11C reg_access_test Lab 11C: do the enable bits and the counters behave? Packets in, counters read through the model.
    reg_introspection_test 11C reg_access_test Lab 11C (optional): the model tells the test which registers are RW and which are RO, then every one is checked.
    back_to_back_test test plan reg_function_test Test plan: the input port with the shortest gap -- a header in the cycle right after the parity byte -- and gaps of 1, 2 and 3 cycles.
    backpressure_test test plan reg_function_test Test plan: the YAPP handshake under back-pressure -- slow receivers fill the 16-byte channel FIFOs, the router stalls the input with in_suspend and no byte is lost.
    counter_wrap_test test plan reg_function_test Test plan: an 8-bit counter wraps from 255 to 0 -- the specification is silent, the Decisions of dut/spec.md fix the choice.
    hbus_protocol_test test plan reg_access_test Test plan: the host port on the wire -- one-cycle writes, two-cycle reads, tri-state after the access, unmapped addresses -- with raw HBUS sequences, no register model.
    hbus_sweep_test test plan base_test Test plan: the HBUS side of the coverage -- every address of the router read and written, checked against the reference model, until the four HBUS collectors reach 100 %.
    parity_error_test test plan reg_function_test Test plan: what a wrong parity byte does -- the counter counts it (when enabled), error pulses 1..10 cycles later, and the packet is still delivered.
    pkt_mem_test test plan reg_function_test Test plan: the packet memory and mem_size_reg hold the last packet, byte by byte, even when the packet was dropped.
    random_backpressure_test test plan random_test Random tests: back-pressure on a random mix of channels -- slow and stalling receivers against long packets sent back to back.
    random_config_test test plan random_test Random tests: the configuration space -- every maxpktsize edge, the router off, mixed counter enables -- under many short bursts.
    random_parity_test test plan random_test Random tests: bad parity where it can happen -- forwarded, dropped (address 3, oversized) and ignored (router off) -- and storms of overlapping bad packets.
    random_test test plan base_test Random tests: the seed decides the shape of the test, and every result is checked automatically -- no expected value is written by hand.
    reg_bit_walk_test test plan reg_access_test Test plan: every bit of every register obeys its policy -- walking ones and zeros through the RW registers, writes ignored by the RO ones.
    router_disable_test test plan reg_function_test Test plan: router_en = 0 makes the router deaf -- nothing reaches a channel, nothing is counted, nothing is stored; traffic resumes when it is enabled again.
    router_filter_test test plan reg_function_test Test plan: the drop rules around the maxpktsize limit and the counters behind them, with the counters enabled and then disabled.

    Sequences¶

    Every sequence class, by package, with the sequencer it runs on. Generated from the model by make map.

    Sequence Package Lab Runs on What it does
    yapp_base_seq YAPP UVC 3 yapp_packet sequencer Base of every YAPP sequence: raises/drops the objection of the starting phase.
    yapp_5_packets YAPP UVC 3 yapp_packet sequencer Five random packets (uvm_do).
    six_yapp_seq YAPP UVC 5 yapp_packet sequencer Six random packets -- a sequence that runs another sequence (uvm_do of yapp_5_packets + 1).
    yapp_012_seq YAPP UVC 5 yapp_packet sequencer Three packets to addresses 0, 1, 2 in order.
    yapp_111_seq YAPP UVC 5 yapp_packet sequencer Three packets to address 1.
    yapp_1_seq YAPP UVC 5 yapp_packet sequencer One random packet.
    yapp_exhaustive_seq YAPP UVC 5 yapp_packet sequencer Runs the whole library once: 1, 012, 111, repeat_addr, incr_payload, rnd, six.
    yapp_incr_payload_seq YAPP UVC 5 yapp_packet sequencer One packet with payload 0,1,2,... and the parity recomputed afterwards.
    yapp_repeat_addr_seq YAPP UVC 5 yapp_packet sequencer Two packets with the same random address.
    yapp_rnd_seq YAPP UVC 5 yapp_packet sequencer count random packets (default 5).
    yapp_88_packets_seq YAPP UVC 7 yapp_packet sequencer 88 packets -- enough to fill a 16-byte channel FIFO and exercise in_suspend.
    yapp_coverage_seq YAPP UVC 10 yapp_packet sequencer 40 packets with the legal-address constraint switched off, to fill the covergroup.
    yapp_boundary_seq YAPP UVC test plan yapp_packet sequencer Lengths maxpktsize-1, maxpktsize, maxpktsize+1 and 63 to every address incl. 3; counts what it sent.
    yapp_gap_seq YAPP UVC test plan yapp_packet sequencer Short packets with gaps 0, 1, 2, 3 in turn (m_packet_delay = idle cycles); counts the gaps it asked for.
    yapp_pkt_seq YAPP UVC test plan yapp_packet sequencer One packet whose address, length and parity the test chooses (soft constraints); the packet stays in req.
    yapp_random_burst_seq YAPP UVC test plan yapp_packet sequencer Random tests: per packet, address (3 included), length class (short, long, around maxpktsize), parity and gap drawn from knobs.
    hbus_base_seq HBUS UVC 7 hbus_transaction sequencer Base of the HBUS sequences; objection handling.
    hbus_large_packet_seq HBUS UVC 7 hbus_transaction sequencer ctrl_reg (maxpktsize) = 63.
    hbus_read_max_pkt_seq HBUS UVC 7 hbus_transaction sequencer Reads ctrl_reg and prints maxpktsize.
    hbus_read_seq HBUS UVC 7 hbus_transaction sequencer One read from haddr; the result lands in the item.
    hbus_set_default_regs_seq HBUS UVC 7 hbus_transaction sequencer Writes the reset defaults: ctrl_reg = 0x3f, en_reg = 0x01.
    hbus_small_packet_seq HBUS UVC 7 hbus_transaction sequencer ctrl_reg (maxpktsize) = 20, en_reg = 1.
    hbus_write_seq HBUS UVC 7 hbus_transaction sequencer One write to haddr with hdata.
    hbus_router_disable_seq HBUS UVC 11C hbus_transaction sequencer en_reg = 0: the router ignores its input.
    hbus_router_enable_seq HBUS UVC 11C hbus_transaction sequencer en_reg = 1.
    channel_rx_base_seq Channel UVC 7 channel_packet sequencer Base of the channel sequences (no objection: responders run forever).
    channel_rx_fast_seq Channel UVC 7 channel_packet sequencer Forever: receive with no delay.
    channel_rx_resp_seq Channel UVC 7 channel_packet sequencer Forever: receive the next packet with a random delay 0..10.
    channel_rx_random_seq Channel UVC test plan channel_packet sequencer Forever: a receiver with a profile -- fast, normal, slow, or stalling 50..150 cycles now and then (between packets).
    channel_rx_slow_seq Channel UVC test plan channel_packet sequencer Forever: answer 20..40 cycles late, so long packets fill the FIFO and the router stalls the input.
    clock_and_reset_base_seq Clock & Reset UVC 7 clock_and_reset_transaction sequencer Base sequence with objection handling.
    clk10_rst5_seq Clock & Reset UVC 7 clock_and_reset_transaction sequencer 10 ns clock, reset held for 5 cycles -- the default in every test.
    clk_rst_rand_seq Clock & Reset UVC 7 clock_and_reset_transaction sequencer Random period and reset length.
    router_mcseq_base Testbench & tests 8 uvm_sequence_item sequencer Base of the multichannel sequences; uvm_declare_p_sequencer(router_mcsequencer), and the shared helpers hbus_write(), hbus_read() and stage().
    router_simple_mcseq Testbench & tests 8 uvm_sequence_item sequencer Programs maxpktsize = 20, sends 6 short packets, then maxpktsize = 63 and 6 random packets.
    router_hbus_sweep_mcseq Testbench & tests test plan uvm_sequence_item sequencer Every HBUS address written and read (registers, holes, both memories), walking bits, yapp_mem patterns, 1020 packets that take the counters to 255.
    router_random_mcseq Testbench & tests test plan uvm_sequence_item sequencer Random tests: 10..100 packets in bursts, a random configuration before each, random HBUS reads, every register read at the end.
